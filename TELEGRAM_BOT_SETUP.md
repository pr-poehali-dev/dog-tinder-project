# 🤖 Настройка Telegram бота для авторизации

## Проблема
Авторизация через Telegram не работает, потому что бот еще не создан.

## Решение: Создание бота за 3 минуты

### Шаг 1: Создайте бота в Telegram

1. **Откройте Telegram** и найдите **@BotFather**
2. Отправьте команду `/newbot`
3. Введите **название бота** (например: `TinDog Auth Bot`)
4. Введите **username бота** (должен заканчиваться на `bot`, например: `tindog_auth_bot`)

✅ **BotFather выдаст вам:**
- **Токен бота** (например: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)
- **Username бота** (например: `tindog_auth_bot`)

---

### Шаг 2: Добавьте данные в проект

#### 2.1 Добавьте секреты в poehali.dev

В редакторе poehali.dev **уже созданы** два секрета для Telegram:

1. **TELEGRAM_BOT_TOKEN**
   - Значение: токен из @BotFather (например: `123456789:ABCdefGHI...`)

2. **TELEGRAM_BOT_USERNAME**
   - Значение: username бота БЕЗ знака @ (например: `tindog_auth_bot`)

⚠️ **Важно:** Откройте настройки проекта и заполните эти секреты!

#### 2.2 Обновите файл .env

Откройте файл `.env` в корне проекта и укажите username бота:

```env
VITE_TELEGRAM_BOT_USERNAME=tindog_auth_bot
```

(Замените `tindog_auth_bot` на ваш username)

---

### Шаг 3: Настройте команды бота

Отправьте @BotFather команду `/setcommands` и выберите вашего бота.

Вставьте текст:

```
start - Авторизация на сайте TinDog
```

---

### Шаг 4: Перезапустите проект

После добавления секретов и обновления .env:
1. Сохраните изменения
2. Перезапустите проект в poehali.dev

---

## ✅ Готово!

Теперь при нажатии на кнопку "Войти через Telegram":
1. Откроется ваш бот
2. Пользователь нажмет `/start`
3. Бот отправит ссылку для входа
4. После перехода по ссылке — авторизация завершится

---

## Проверка работы

1. Откройте сайт в **отдельной вкладке** (не в редакторе)
2. Нажмите "Войти через Telegram"
3. Перейдите в бота и нажмите `/start`
4. Бот должен отправить ссылку для входа

⚠️ **Если бот не отвечает** — проверьте, что:
- В секретах правильно указан `TELEGRAM_BOT_TOKEN`
- Backend функция `telegram-bot-telegram-bot` развернута (есть в `func2url.json`)

---

## Дополнительно: Настройка Webhook

Backend функция автоматически настроит webhook при первом запуске.

Если нужно проверить статус webhook:
```bash
curl https://api.telegram.org/bot<ВАШ_ТОКЕН>/getWebhookInfo
```
